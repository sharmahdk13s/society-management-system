# Society Management System #

  1. Authentication and Authorization
    • Registration/Login with JWT Auth:
      • Enable secure user registration and login using JSON Web Tokens (JWT) for stateless authentication.
    • Role-Based Access:
      • Assign roles (SuperAdmin, Admin, Member) with specific permissions to control feature access.
  2. User Management
    • Perform CRUD operations on users accounts.
    • Manage roles and permissions.
  3. Maintenance and Rent Management
    • CRUD operations for maintenance Status, Rented house
    • House number wise donation or raising funds status.
    • Celebration or functions events updates
    • Visitors entry and status.
    • Update operations.
  4. Buy existing house
    • Record of buyer with token amount.
